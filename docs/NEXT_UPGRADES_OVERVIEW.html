AgentDesk — next upgrades

Polyglot, cutting-edge, Python stays the spine. Other languages take the hot paths, the Windows-native edges, and the façades where each ecosystem lives. Free / open-source only.

Language split of new code

Python 55%
TS 25%
Rust 10%
C++ 6%
C# 4%

Three interop tiers

In-process

PyO3 · pybind11

Hot pure functions: DOM diff, content refs, scrubbing, token counting. Import failure → transparent Python fallback.

Sidecar

Named pipe · NDJSON

Windows-native UIA3, ConPTY terminal, native CDP driver. Crash → auto-respawn, tool returns a clear error.

Network

OpenAPI 3.1

External SDKs in TS, C#, C++, Go. One contract, generated clients per language — no hand-editing, no drift.

Sequencing rule: no phase starts before the previous phase's acceptance criteria are met and the app installs and passes the smoke test. Every native path has a Python fallback — the app must never break because a binary is missing.
