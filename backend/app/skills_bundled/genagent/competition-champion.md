# Skill: Competition Champion

## When to use
Any competitive task: hackathons, coding contests, Kaggle-style competitions, essay/pitch contests, online challenges with scoring, ranking, prizes, or deadlines. Use whenever the user says "win", "compete", "submit", "rank", or names a competition.

## Winner mindset (always active)
- Play to WIN, not just to participate. Aim for 1st; accept nothing below top-3 without a fight.
- Attack scoring rubrics directly: every point matters. Find the highest value-per-effort items first.
- Time-box hard. A submitted 85% solution beats an unsubmitted 100% solution, every time.
- Stay positive and decisive. No excuses, no overthinking. Make the best move available NOW.
- Verify before submitting. Winners never lose on technicalities (wrong file, wrong format, missed requirement).

## Playbook
1. **Intel (5-15 min max)**: web_search the competition name, rules, scoring rubric, past winners, judging criteria, deadline, submission format/portal.
2. **Strategy**: list what wins points; pick the plan with the best score-per-hour. Prefer a strong, complete core over fancy unfinished extras.
3. **Build with muscle**: delegate heavy generation (full code drafts, essays, slides, models) to the strongest free worker (gateway big model or web deck), run/test locally, iterate.
4. **Edge-case pass**: test with weird inputs, empty files, big numbers. Fix crashes first, then polish.
5. **Polish that judges see**: clear README, demo, screenshots, 60-second pitch. Presentation is free points.
6. **Submit early**: submit a valid version as soon as it works, then keep improving and resubmit if allowed.
7. **Proof**: screenshot/save the confirmation. Report to the user with time to spare.

## Submission automation
- If the portal is a web page: open it in the Web Deck (browser panel), read the form with the browser tool, fill and submit via Playwright MCP if available, else guide the user in one screen.
- Attach files exactly as specified (name, format, size limits). Double-check before the final click.

## Rules of engagement
- Never fake results or plagiarize; winners win on merit. Original work, honest numbers.
- If registration/payment is required, stop and tell the user exactly what is needed.
- If the deadline is impossibly close, submit the strongest achievable version and say what was skipped.
